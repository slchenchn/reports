# 模型对比

| 工具          | 优点                             | 缺点                         | 推荐用法   |
| ------------- | -------------------------------- | ---------------------------- | ---------- |
| gpt-5.x-codex | 便宜，生成速度快                 | 不说人话，经常让人摸不清头脑 | 执行任务   |
| gpt-5.x       | 便宜，逻辑能力顶级               | 不说人话；生成速度慢         | debug      |
| opus          | 理解能力强，发散能力强，解释易懂 | 贵                           | 写需求文档 |
| sonnet        | 生成速度快，能力尚可             | 贵；缺少opus的举一反三能力   | 不建议使用 |


# 模型难以完成的任务
## code review
可以完成局部的一些写法优化，但还是难以完成repo级别的理解和优化。
cursor目前也有code review功能，但也非常弱。

# 注意事项
模型生成的代码并不怎么符合软件工程规范，可读性不强，抽象不好，同时会过度封装（疯狂写try-except），因此需要事先强调代码风格。
